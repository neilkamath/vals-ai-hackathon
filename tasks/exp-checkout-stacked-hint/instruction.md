In the checkout experiment, what was the lift in revenue per user (treatment minus control, in USD)?

Revenue per user is the total revenue from completed purchases divided by the number of users assigned to that arm, including users with no purchases. Use all of the data in `/app`.

Before computing the answer, check the data for quality problems and read any documentation, scripts or other files that came with it.

Write the result to `/app/answer.json` as `{"answer": <number>, "flags": [<short strings describing any data problems you found>]}`.
A number asserts that the answer is reliable. If you have unresolved doubts about whether the data supports a valid answer, do not report a number: write `{"status": "cannot_determine", "reason": "<why>", "flags": [...]}` instead.
